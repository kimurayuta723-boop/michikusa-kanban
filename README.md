# みちくさ看板

散歩で見つけたかわいい看板やサインを集める、自分専用の看板図鑑です。
iPhoneのSafariで使うことを想定したWebアプリ(PWA)で、GitHub Pagesにそのまま置けます。

## できること

- **撮影・切り抜き**:カメラで撮るか写真ライブラリから選び、看板の部分だけを切り抜きます。
- **場所の記録**:登録時の現在地を保存します。地図上でピンをドラッグして直せます。
- **色の抽出**:写真から主な色を3つ取り出し、伝統色の名前を付けます。
- **タグの推測**:
  - 色調(パステル/ビビッド/くすみ/モノトーン)は、色の分析で推測します。
  - モチーフと質感は、端末内のAI(CLIP)で推測します。
  - 推測したタグはミントの点線で表示され、タップで付け外しできます。
- **図鑑・地図**:ステッカー風の一覧と、ピンが丸いサムネイルになった地図で見返せます。
- **「まだある?」**:再訪したときに「あった/なくなった」を記録します。なくなった看板はセピア色になります。
- **バックアップ**:写真ごとJSONファイルに書き出し、読み込めます(設定から)。

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作ります(例:`michikusa-kanban`、Public)。
2. 「Add file」→「Upload files」で、このフォルダの中身をすべてアップロードします。
   - `index.html` がリポジトリの一番上に来るようにしてください。
   - `.nojekyll` も一緒に入れてください。
3. 「Settings」→「Pages」で、Sourceを「Deploy from a branch」、Branchを `main` / `(root)` にして保存します。
4. 数分待つと、`https://<ユーザー名>.github.io/michikusa-kanban/` で開けるようになります。

## iPhoneでの使い方

1. 公開したURLをSafariで開きます。
2. 共有ボタンから「ホーム画面に追加」します。
   - ホーム画面から開くと全画面で使えます。
   - Safariが写真や記録を自動で消しにくくなります。
3. 初回の撮影時に、位置情報とカメラの許可を求められます。
4. 初回のAI推測で、AIのデータ(百数十MB程度)をダウンロードします。
   - Wi-Fiでの利用がおすすめです。2回目以降は端末内のキャッシュから読むので速くなります。
   - AIを使わない場合は、設定でオフにできます。

## データについて

- 写真と記録は、すべてiPhoneの中(IndexedDB)にだけ保存されます。サーバーには送りません。
- AIの推測も端末内で行い、写真は外に出ません。
- 機種変更やSafariのデータ削除に備えて、ときどき「バックアップを書き出す」で保存しておくと安心です。

## ファイル構成

```
index.html            画面の骨組み
css/style.css         見た目(色・フォント・レイアウト)
js/app.js             画面の動き(図鑑・地図・詳細・登録フロー・設定)
js/db.js              端末内保存とバックアップ
js/image.js           写真の読み込み・切り抜き・縮小
js/color.js           色の抽出・伝統色の名前・色調の推測
js/tagger.js          端末内AIによるタグ推測
js/tags.js            タグの一覧(ここを編集するとタグを増減できます)
js/mascot.js          キャラクター「あるく看板」のSVG
sw.js                 オフライン用のキャッシュ
manifest.webmanifest  ホーム画面に追加したときの名前・アイコン
icons/                アプリアイコン
```

## カスタマイズのヒント

- **タグを増やす**:`js/tags.js` に項目を足します。AIで推測させるタグには、英語の説明文(`prompt`)を付けてください。
- **地図の初期位置**:`js/app.js` の `DEFAULT_CENTER` を変えます(位置情報も登録済みの看板もないときだけ使います)。
- **更新を反映させる**:ファイルを更新したら、`sw.js` の `VERSION` を `v2` のように上げてください。古いキャッシュが残りにくくなります。
